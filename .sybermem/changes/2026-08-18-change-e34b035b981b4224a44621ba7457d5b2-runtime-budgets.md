## Change Content

新增 `budgets.mjs`：

- standard/complex investigation budget defaults and config overrides；
- specialist timeout、child timeout、最大 specialist 数和最大 investigation round；
- deadline/remaining budget 计算；
- specialist 是否还可启动判断；
- timeout 分类：investigation/specialist 可重试，fixing/verifying 需要 clean-branch check。

## Reason for Change

无人值守 investigation 需要有限时间/数量边界，避免 specialist 或 child run 无限执行、静默占用 N=1 锁。先实现纯预算契约，再在后续 runtime adapter 接入。

## Impact Scope

仅新增纯模块和测试，当前 scheduler 行为不变。
