## Change Content

- `qa-verdict.mjs` 增加 report hash、verdict build 和 auditQaVerdict；
- scheduler run 结束后读取 `qa-verdict.json`，校验 issue/branch/status/time/hash，写入 `qa_verdict_*` 和 phase/error state；
- 缺失或非 PASS verdict 会记录 `qa-unapproved`，不被视为 QA 成功；
- 全套 Guardian 测试达到 199/199。

## Reason for Change

review 指出 QA PASS 主要存在 agent prose/harness，缺少机器可审计的 verdict artifact。本批先建立并接入运行后审计；PR 前分阶段执行仍需后续拆分 fixer/qa/PR。

## Impact Scope

QA 结果审计和 state metadata；不自动 merge/close，不改变 trusted author、N=1、Gate2 安全边界。

`node --test "tests/guardian/*.test.mjs"` → 199/199 pass。

## Notes
