## Change Content

新增四个正交只读调查角色：

- guardian-code：符号、调用链、影响面、测试和 git history；
- guardian-business：业务规则、状态机、枚举、历史、未确定事实；
- guardian-runtime：本地测试/临时 probe/输入输出复现，不安装依赖；
- guardian-docs：仅在依赖契约决定结果时查询官方 Context7 文档。

qa-guardian task whitelist 新增这四个明确角色，仍拒绝任意 agent、写入、安装、生产访问、merge/close；bootstrap 同步安装全部 specialist 文件。

## Reason for Change

单一 write-capable qa-guardian 的复杂 bug/request 调查质量低于 Sisyphus，需要把调查拆成独立只读视角，同时保留修复角色与独立 qa 质检分离。

## Impact Scope

新增 agent 定义和安装路径；尚未接入 MCP capability discovery 或 investigation coordinator，后续阶段接入。
