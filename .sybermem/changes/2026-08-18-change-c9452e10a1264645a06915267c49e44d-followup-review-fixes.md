## Change Content

- `followup` 加入 Feishu callback 的必填文本命令集合，空 DONE followup 现在在回调边界被拒绝，不会写无效 `/guardian followup` 评论。
- scheduler 的通知候选增加 `GATE_1_WAIT`、`GATE_2_WAIT`，并识别 `gate1-waiting`/`gate2-waiting` 的 SKIP 决策，Gate 卡片可以真实投递。
- `notify-io.mjs` 映射 Gate 状态到对应卡片。
- `startFollowupRound` 清空 `last_notified_state`，确保新验收轮次完成后 DONE 卡片再次可投递。
- 新增/更新回归测试，覆盖空 followup、Gate 通知、跨轮次通知标记和 DONE followup 验收场景 UC-L。

## Reason for Change

review-work 发现：DONE 卡片空输入会生成被 poller 忽略的无效命令；Gate 1/Gate 2 卡片定义存在但 scheduler 通知路径未接通；上一轮 DONE 通知标记可能抑制下一轮 DONE 通知。

## Impact Scope

Feishu followup 交互、Gate 通知、处理轮次通知幂等；不改变 trusted author、N=1、只写 GitHub comment、不 merge/close 的安全边界。
