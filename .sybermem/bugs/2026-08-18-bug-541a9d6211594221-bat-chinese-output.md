## Bug Description

双击 scheduler-start.bat 后出现大量 `'uardian'`、`'ns'`、`'M'`、`'Double-click'` 未找到命令，并且中文引导显示乱码。

## Root Cause

1. bat 的 if 分支执行后未跳转到 done，cmd 继续 fall-through 到后续标签，重复调用 PowerShell。
2. Windows PowerShell 5.1 对无 BOM UTF-8 中文脚本按系统代码页解析，改成中文后出现解析错误。
3. bat 控制台未切换 UTF-8，PowerShell 输出与 cmd 代码页不一致造成中文乱码。

## Solution

bat 改为纯 ASCII、显式 goto done；bat 启动先 `chcp 65001`；scheduler-start.ps1 使用 UTF-8 BOM 并设置 Console/OutputEncoding。cmd 冒烟确认不存在的目标目录只调用一次并输出单条中文错误。

## Prevention Measures

Windows `.bat` 入口避免括号分支 fall-through；含中文的 PowerShell 5.1 脚本保留 UTF-8 BOM；bat 显式设置 UTF-8 code page。
